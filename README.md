# qrain_jinlin_AI
> Classic deep‑learning papers reproduction & improvement project

本项目参考六篇AI论文：
AlexNet、Transformer、BERT、Adam、DQN、RLVR。

## 本项目（qrain_jinlin_AI）的目的有
- 打破国外人工智能AI壁垒
- 增加中国国产AI数量与质量
- 将代码开源，展示AI技术

> ⚠️ 本仓库图片素材较少，原因与依据见 [ASSETS_POLICY.md](./ASSETS_POLICY.md)。
> ⚠️ 素材说明
> 仓库附带作者原创手绘测试图片，用于图像模块调试，遵循Apache 2.0协议；
> 素材体量小，仅用于代码链路验证与模型训练
> 如需正式训练，请自行准备合规数据集。
> 论文文档不含原版图表，请查阅 [docs/论文中无插图通告.md](./docs/论文中无插图通告.md)；原图请跳转各论文官方页面。

## Project structure
- `docs/`：阅读笔记、译文、工程控制手册、通告文档
- `src/`：Python / C++ 源代码实现
- `tools/`：本地辅助工具脚本
- `scripts/`：资源下载调用入口

> 预训练权重、数据集不上传仓库，通过 Release / 外部下载获取。
