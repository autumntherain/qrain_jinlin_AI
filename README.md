# qrain_jinlin_AI
> Classic deep‑learning papers reproduction & improvement project

本项目复现并改良六篇深度学习经典论文：
AlexNet、Transformer、BERT、Adam、DQN、RLVR。

## 项目愿景
- 攻克国外人工智能技术壁垒，实现自主可控
- 扩充国产 AI 供给规模，持续迭代提升模型质量
- 项目代码完全开源，支持生产环境可视化运维

> ⚠️ 本仓库图片素材较少，规则说明详见 [ASSETS_POLICY.md](./ASSETS_POLICY.md)。
> ⚠️ 素材说明
> 仓库附带作者原创手绘测试图片，用于图像模块调试，遵循Apache 2.0协议；
> 素材体量小，仅用于代码链路验证与小规模调试；
> 如需大规模正式训练，请自行准备合规数据集。
> 论文文档不含原版图表，请查阅 [docs/论文中无插图通告.md](./docs/论文中无插图通告.md)；原图请跳转各论文官方页面。

## Project structure
- `docs/`：阅读笔记、译文、工程控制手册、通告文档
- `src/`：Python / C++ 源代码实现
- `tools/`：本地辅助工具脚本
- `scripts/`：资源下载调用入口

> 预训练权重、大规模数据集不上传仓库，可通过 Release / 外部合规渠道获取。
