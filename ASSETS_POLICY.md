# ASSETS POLICY / 素材政策

本仓库包含少量图像素材，全部由本项目作者独立创作，著作权归作者所有。

This repository contains a small set of image assets, all of which are
independently created by the project author. Copyright of these assets
belongs to the author.

## 使用规则 / Terms

1. 所有附带图像素材遵循 Apache License 2.0 许可协议分发，与源代码使用相同许可条款。
   All bundled image assets are distributed under the Apache License 2.0,
   the same license as the source code.

2. 素材仅用于本项目图像加载流水线调试、模型前向验证、图像预处理模块小规模调试。
   The assets are only used for small-scale engineering debugging of the image
   loading pipeline, model forward pass, and preprocessing modules.

3. 禁止将本项目内附带图像素材单独剥离出来，用于独立商用、二次分发、制作其他数据集。
   You may not extract the assets for standalone commercial use, redistribution,
   or building another dataset.

4. 本素材不是公开基准数据集，不用于大规模对标实验。
   The assets are NOT a public benchmark dataset and must not be used for
   large-scale benchmarking.

5. 本仓库不包含任何原版论文配图、第三方网络图片、AI 生成图像、实拍含肖像内容。
   This repository contains NO original paper figures, third-party web images,
   AI-generated images, or real photos containing identifiable people.
